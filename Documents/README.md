# 🎧 Audio-Based Deepfake Detection Using ECAPA-TDNN

🚀 **DB-12 Academic Project Repository**  
An efficient and robust **audio-only deepfake detection system** leveraging **ECAPA-TDNN speaker embeddings** and a lightweight **binary classifier**, evaluated on the **TIMIT-TTS dataset**.

---

## 📌 Project Overview

The rapid progress of **Text-to-Speech (TTS)** systems has made synthetic voices nearly indistinguishable from real human speech, posing serious risks such as:

⚠️ Voice impersonation  
⚠️ Misinformation  
⚠️ Bypassing voice authentication systems  

This project proposes a **lightweight, embedding-based deepfake detection framework** that operates entirely in the **speaker embedding space**, achieving high accuracy while remaining suitable for **real-time deployment**.

---

## 🎯 Key Contributions

✅ Audio-only deepfake detection (no visual data required)  
✅ ECAPA-TDNN speaker embeddings for robust feature extraction  
✅ Simple yet effective **logistic regression classifier**  
✅ Strong generalization across multiple TTS systems  
✅ Outperforms **RawNet2** baseline under multiple conditions

## 🧪 Dataset Used

### 🗃️ TIMIT-TTS Corpus

- 🎙️ Nearly **80,000 audio samples**
- 👤 **37 speakers**
- 🤖 Speech generated by **12 TTS models**
- 🔁 Real & synthetic paired samples
- 🎚️ Sampling rate: **16 kHz**
- ⏱️ Avg duration: ~3 seconds  

**Train/Test Split:** 80% / 20%

---

## ⚙️ System Pipeline

### 🔊 Audio Deepfake Detection Flow

Raw Audio
↓
Preprocessing (Mono, 16 kHz, Normalization)
↓
ECAPA-TDNN Speaker Embeddings
↓
Z-score Normalization
↓
Logistic Regression Classifier
↓
Real / Fake Prediction


---

## 📊 Performance Highlights

📈 **Accuracy:** ~90%  
📈 **F1-Score:** 0.92  
📈 **ROC-AUC:** 0.93  
⚡ **Low inference latency (real-time capable)**  

### 🆚 Baseline Comparison

| Model        | Accuracy | F1-Score | AUC |
|--------------|----------|----------|-----|
| ECAPA-TDNN   | 94.7%    | 0.95     | 0.98 |
| RawNet2      | 88.3%    | 0.89     | 0.92 |

✔️ ECAPA-TDNN consistently outperforms RawNet2 across:
- Clean audio  
- Augmented audio  
- DTW-aligned conditions
